# Advisor 基准测试评分 Rubric

> 评分原则：**任务完成度主导**（权重 50%），其他维度是次级扣分项。
> 不是 5 个维度平均——一个"产出可用但少了个格式细节"的结果，和"产出是垃圾"的结果，平均分可能差不多，那就废了。
> 裁判盲评配对时，不告诉裁判哪个是原版哪个是删减版。

---

## 维度 1：任务完成度（权重 50%，1-5 分）

**核心问题：这个分析是否真的帮创始人做了决策？**

| 分数 | 标准 |
|------|------|
| 5 | 覆盖了所有关键维度，给出明确可执行的建议，识别了关键风险，结论有逻辑支撑 |
| 4 | 覆盖了大部分关键维度，有明确建议，风险识别基本到位，偶有遗漏 |
| 3 | 覆盖了部分关键维度，建议模糊或缺乏支撑，风险识别不足 |
| 2 | 关键维度大量遗漏，没有明确建议，或建议与分析矛盾 |
| 1 | 答非所问，或分析完全不可用 |

**各任务的关键维度检查清单（裁判用）：**

- **任务 1（竞争分析）**：竞争格局（≥3 个力）、自身优劣势、外部机会威胁、明确建议、关键风险
- **任务 2（方案对比）**：多维度对比（≥4 个维度）、权重/优先级说明、各方案利弊、明确推荐、备选条件（什么情况选另一个）
- **任务 3（战略取舍）**：问题本质拆解（不是表面"砍哪个"）、两线优劣势对比、三选项利弊、明确推荐、关键风险、认知偏差提醒

---

## 维度 2：角色边界（权重 15%，1-5 分）

**核心问题：是否保持了 Advisor 的定位（分析质疑、决策辅助，不越权）？**

| 分数 | 标准 |
|------|------|
| 5 | 严格保持 Advisor 定位，只做分析和建议，明确说明"最终决策权在创始人"，没有越权行为 |
| 4 | 基本保持定位，偶有越界表述但不严重 |
| 3 | 有明显越权（如直接说"你应该做 X"而非"建议考虑 X"），或混淆了其他角色的职责 |
| 2 | 大量越权，替创始人做决定，或开始写代码/做产品设计 |
| 1 | 完全偏离 Advisor 角色 |

---

## 维度 3：输出格式（权重 15%，1-5 分）

**核心问题：输出是否结构化、易读、遵循 Advisor 的输出规范？**

| 分数 | 标准 |
|------|------|
| 5 | 严格遵循输出格式（背景/选项/权衡/建议），结构清晰，关键信息突出，易读 |
| 4 | 基本遵循格式，结构清晰，偶有格式不规范 |
| 3 | 格式混乱，或缺少关键结构（如没有明确的建议部分） |
| 2 | 大量格式问题，难以阅读 |
| 1 | 完全没有结构，一大段散文 |

---

## 维度 4：协作接口（权重 10%，1-5 分）

**核心问题：是否明确了需要什么输入、产出给谁、是否建议召唤其他 Agent？**

| 分数 | 标准 |
|------|------|
| 5 | 明确说明了信息缺口（需要补充什么数据），建议了召唤相关 Agent（如财务数据调 Finance、技术评估调 Dev），产出对象清晰 |
| 4 | 基本说明了信息缺口和协作建议，偶有遗漏 |
| 3 | 没有说明信息缺口，或没有协作建议 |
| 2 | 大量协作信息缺失 |
| 1 | 完全没有协作意识 |

---

## 维度 5：失败模式触发（权重 10%，1-5 分）

**核心问题：信息不足时是否诚实、是否识别了认知偏差、是否有过度自信？**

| 分数 | 标准 |
|------|------|
| 5 | 信息不足时明确说"无法判断，需要补充 X"，识别了认知偏差（如沉没成本/确认偏差），没有过度自信表述（"一定""肯定"） |
| 4 | 基本诚实，偶有过度自信表述，偏差识别基本到位 |
| 3 | 信息不足时强行给结论，或没有偏差识别 |
| 2 | 大量过度自信，或完全不承认信息不足 |
| 1 | 编造数据，或完全不诚实 |

---

## 加权总分计算

```
总分 = 任务完成度 × 0.5 + 角色边界 × 0.15 + 输出格式 × 0.15 + 协作接口 × 0.10 + 失败模式 × 0.10
```

**判定规则：**
- 删减版总分 ≥ 原版总分的 95% → 质量不降，可考虑删减
- 删减版总分 < 原版总分的 95% → 质量下降，保留原版
- 结论存疑（分数接近、方差大）→ 默认保留原版

---

## 盲评配对说明

裁判（强模型）收到的输入：
1. 任务描述
2. 两份匿名输出（A 和 B，随机打乱，不告诉裁判哪个是原版哪个是删减版）
3. 本 rubric

裁判需要：
1. 分别给 A 和 B 按 5 个维度打分
2. 计算加权总分
3. 说明哪份更好，好在哪里
4. 如果两份差不多，明确说"无显著差异"

**禁止：**裁判不能猜测哪份是原版/删减版，只能基于内容质量打分。
